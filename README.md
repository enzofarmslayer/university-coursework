# University coursework

Lab assignments from my studies at Linköping University (LiU), where I'm an MSc in Engineering student in Computer Engineering, specializing in AI and Machine Learning.

Each course has its own folder. The labs were originally developed in LiU's GitLab, and their full commit history is kept here. Most labs were done in pairs, so commits from lab partners and course staff (who provide the starter code) also appear in the history.

## Courses

| Course | Language | What the labs cover |
| --- | --- | --- |
| [TDDE23](TDDE23) – Functional and imperative programming, part 1 | Python | Recursion, a small logic expression interpreter, binary trees, and image processing with OpenCV (pixel filters, generators, combining images). |
| [TDDE24](TDDE24) – Functional and imperative programming, part 2 | Python | An interpreter for a small calculator language, recursive pattern matching and search over a book database, tree traversal with higher-order functions, and a calendar booking system built on abstract data types. |
| [TDDE30](TDDE30) – Object-oriented programming | Java | Java basics, a stack and queue, a shapes hierarchy with a Swing diagram viewer, a calendar, and a full Tetris game with a GUI, high score list and power-ups. |
| [TDDD86](TDDD86) – Data structures, algorithms and programming paradigms | C++ (Qt) | Game of Life, Evil Hangman and word chains, TSP heuristics with linked lists, Robots, Boggle, a fish market simulation with a custom priority queue, pattern recognition (collinear points), path finding with DFS, BFS, Dijkstra and A* (Trailblazer), and Huffman compression. |
| [TDDE68](TDDE68) – Operating systems | C | Extending the Pintos teaching OS: system calls, user program loading and argument passing, process management (exec, wait, exit), pointer validation, and synchronization in the file system. |
| [TDDE77](TDDE77) – Machine learning | Python (Jupyter) | NumPy and pandas fundamentals, and linear regression, nonlinear feature transformations and regularization with scikit-learn. |
